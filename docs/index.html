ARIA

Adaptive Realtime Intelligence Avatar

A real-time AI companion that sees you in your browser, listens, thinks with Claude, remembers you, and answers as a live 3D avatar.

View on GitHub Quickstart

What is ARIA?

Your browser watches your face and hands with MediaPipe, your microphone is transcribed to text, Claude reasons about what you said and how you look, a three-tier memory tracks who you are across sessions, and a low-poly 3D avatar answers out loud with an expression that fits the moment.

The honest privacy posture

  • Camera frames never leave your browser. Face and hand tracking run locally; only a small derived signal — an emotion label, head-pose angles, and detection flags — is sent onward.
  • Your microphone audio is streamed to the server so faster-whisper can transcribe it.
  • Your text reaches Claude for reasoning, and the reply is sent to ElevenLabs to be spoken.

Video stays local; audio and text go to the server. ARIA is not a fully on-device system, and does not claim to be.

Features

Everything runs in real time across the browser, a Go edge server, and a Python service.

▹ Browser perception

Camera + mic capture and MediaPipe face/hand tracking, emotion, gesture, and head-pose all run in the browser (WASM/WebGPU).

▹ Voice in, voice out

Mic audio streams to the server, is transcribed by faster-whisper, and ARIA replies with ElevenLabs speech (browser-TTS fallback).

▹ Wake-word gated

Say "Hey ARIA" to wake it; say "that would be all" to send it back to sleep.

▹ Claude cognition

Each turn blends your message, your current expression, working memory, and long-term facts into one prompt for Claude.

▹ Three-tier memory

ChromaDB stores profile, episodic, and working memory so ARIA remembers you between sessions.

▹ Emotion-aware avatar

A low-poly three.js avatar reflects ARIA's response emotion and your head pose in real time.

▹ Spatial canvas

Place and recall anchored objects in a shared 3D space, persisted in SQLite.

▹ Cloud-ready

Authenticated with Clerk and deployable to Railway (backend) + Vercel (frontend).

Architecture

Capture and vision inference happen in the browser. The Go server is the only public process — it verifies the Clerk token, rate-limits, and proxies to a Python service that is never exposed to the internet.

Quickstart

Requires Go 1.26+, Node 20+, Python 3.13 (ARM64 on Apple Silicon), an Anthropic API key, and optionally an ElevenLabs key. Run three terminals:

# Terminal 1 - Python cognition, STT, memory, TTS
cd backend
export $(grep -v '^#' .env | xargs)
PYTHONPATH="$PWD" python3 -m uvicorn app.main:app --port 8000

# Terminal 2 - Go WebSocket server (spawns the audio-worker STT process)
cd backend
go run cmd/server/main.go

# Terminal 3 - Frontend
cd frontend
npm run dev

Open http://localhost:3000, allow camera + microphone, and say "Hey ARIA". Full setup, project structure, and the cloud deploy runbook are in the repository.
